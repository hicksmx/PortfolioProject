Sparkle-on

2023

A Flask-based image server built to dynamically serve daily "Sparkle-on" images for Discord and Slack embeds. The project features a quirky Jerma985 GIF with customized text based on the current day of the week.

Technical Highlights:

  • Python Flask backend for dynamic image generation
  • Custom image processing for text overlay
  • Proper header management for image caching
  • Timezone-aware date handling (Eastern Time)

Note: Due to Discord's aggressive caching policy, the service may occasionally show cached results rather than real-time generated images.
