Slideshow Karaoke

Congressional App Challenge Winner 2021

A web-based game that challenges players to present impromptu talks using random, unrelated images. Created for INTERalliance club and won the Congressional App Challenge for our district.

Project Background

Developed during my sophomore year in high school as part of INTERalliance's tech and business club, this project became the catalyst for my programming journey. Working alongside the club president, we transformed a beloved club ice-breaker into a web application, pushing my early web development skills to their limits.

Technical Highlights

  • Advanced CSS animations creating dynamic logo effects using colored drop-shadows
  • Responsive frontend design accommodating various screen sizes
  • Random image selection and presentation system
  • Collaborative development splitting frontend and backend responsibilities

Learning Outcomes

This project marked my first serious dive into web development, challenging me to:

  • Master complex CSS animations and effects
  • Collaborate effectively on a development team
  • Meet competition deadlines and requirements
  • Present technical work to judges and peers

🏆 Recognition

Winner of the 2021 Congressional App Challenge for our district, demonstrating both technical excellence and practical application in education.
