52 Pickup

2024

Created in a single day during my senior year of high school, this project demonstrates proficiency in JavaScript, CSS, and HTML integration. The game recreates the classic prank "52 Pickup" in web form, challenging players to collect scattered cards as quickly as possible.

Key Technical Features:

  • Interactive sliding sidebar for game controls and information
  • Asset caching system for improved performance
  • CSS animations integrated with JavaScript for card interactions
  • Cookie-based system storing last 10 completion times
  • Random card rotation and positioning algorithms
